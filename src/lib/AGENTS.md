# src/lib rules
- Native Android alarms live in `src/lib/native-alarms.ts` (Capacitor.getPlatform() gate) with pure rules in `native-alarms-core.ts`: next 2 firings × (1 main + 30 follow-ups, none at/after 07:30 device-local; alarm screen closes at 07:30), IDs 1,000,000+ per firing, cap 450, solve cancels only that firing then resyncs. Why: closed-app ringing without touching reminders or iOS.
- Offline wake stop uses phone-made math (`wake-offline-core.ts`, mirrored in `android-shell/offline-core.js` via `server.errorPath`); coins only via `wake_claim_offline` (alarm+scheduled time match, 1/firing, 0–35 min, 48h, 5-min drift, server-computed amount via private `wake_finalize_offline`). Why: no answer keys on device; owner accepted tamper risk.
